# Launchpad

Job search command center for early-career software engineers — track the pipeline, assessments, referrals, and prep in one place.

## Status

Phase 1 in development: project scaffold.

## Planned stack

- Frontend: React + TypeScript
- Backend: Java + Spring Boot
- Database: PostgreSQL
- Tooling: Docker, GitHub Actions

## Structure

- `api/` — Spring Boot backend
- `web/` — React frontend
- `docs/` — architecture decisions and notes
